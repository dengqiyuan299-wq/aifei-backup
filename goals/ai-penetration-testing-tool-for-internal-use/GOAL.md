# AI penetration testing tool for internal use

Goal ID: goal_88c30689cdf4
Goal slug: ai-penetration-testing-tool-for-internal-use

## Description
An AI automated penetration testing tool for the user's own enterprise internal testing, with a scope whitelist, detect-only checks, and a full audit log. Version 1 covers asset discovery, port and service identification, checks, AI triage, and Chinese reporting in MD, HTML, and JSON. Expansion depends on the user's trial in the test segment and review of the report.
