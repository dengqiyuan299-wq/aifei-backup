# Heysocks Windows installer hosting

Goal ID: goal_f7f143aae7f5
Goal slug: heysocks-windows-installer-hosting

## Description
Host the Heysocks Windows installer version 5.7.7 on the user's server and share a direct download link. The phone cannot open or forward the 76 MB Windows-only installer, so the server link is the delivery route for the same account with a fixed US node.
