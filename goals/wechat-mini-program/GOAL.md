# 初羽茶盧 WeChat mini program

Goal ID: goal_48769fb54d33
Goal slug: wechat-mini-program

## Description
One WeChat mini program for 初羽茶盧 combining a tea shop and tea-room booking. The shop lists teas by category for browsing, cart, ordering, and WeChat Pay, while booking covers the first-floor tea room, second-floor tea room, and third-floor salon and meeting space for 10–15 people. The assistant builds the code and the user registers the account, supplies the AppID and payment merchant account, and provides tea photos and prices, which remain placeholders until supplied; only prepackaged foods are sold, so filing rather than a food business licence applies.
