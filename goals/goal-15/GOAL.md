# 邓梓浩七年级七科闭环学习系统

Goal ID: goal_5c3c019107da
Goal slug: goal-15

## Description
Closed-loop learning system for Deng Zihao's seven Grade 7 subjects, built around a skill-tree map, FSRS spaced-review engine, self-rotating error book, and gamified progress. Each subject uses its own learning form, starting with a skeleton app, then poetry data and English and maths samples.
