## 第一条　转让标的债权

1. 甲方转让给乙方的债权（以下简称"标的债权"）为：丙方依据原借款协议欠付的借款本金人民币 **50,000 元**（大写：伍万元整），以及截至实际清偿之日止的利息、逾期利息、违约金、损害赔偿金等全部从权利（如原借款协议无相关约定的，从权利范围以依法可主张者为限）。
2. 标的债权的具体构成、到期日以原借款协议及附件一凭证为准。**如附件凭证显示的欠款金额与本条不一致，以丙方在《债务确认书》（附件三）中确认的金额为准；丙方未出具确认书的，以原借款协议、付款凭证及 A→甲转让文件共同证明的金额为准。**
3. 自本协议生效且乙方付清转让价款之日起，标的债权的全部权利（包括但不限于请求丙方还款、主张利息与违约金、提起诉讼/仲裁、申请强制执行、参与分配等权利）由乙方独享，甲方不得再以自身名义向丙方主张。

## 第三条　甲方的陈述与保证（本协议的核心风险条款）

甲方就标的债权向乙方作出如下陈述与保证，本协议签订之日及债权交割之日均为真实、完整、有效：

1. **债权真实存在**：原借款真实发生，款项已实际交付丙方，债权金额如第一条所述，不存在虚构债务、虚假凭证的情形；
2. **权利完整无瑕疵**：甲方对标的债权享有完整、合法的处分权；债权未被质押、抵押、查封、冻结，未设定任何第三方权利；
3. **未重复转让**：标的债权未曾转让、出售或以任何方式处分给乙方以外的任何第三方；甲方此后亦不再转让；
4. **未获清偿**：丙方尚未向 A 公司或甲方清偿全部或部分款项（已清偿部分金额为 ＿＿ 元，双方已在第一条金额中相应扣减；无清偿的填"0"）；丙方亦未与 A 公司或甲方达成减免、抵销、延期豁免等安排；
5. **无争议无抗辩**：标的债权不存在诉讼、仲裁、执行程序中的争议；就甲方所知，丙方对债权不存在足以对抗乙方的抗辩事由（如有潜在事由，甲方已在本条附件中如实披露：＿＿＿＿＿＿＿＿，无则填"无"）；
6. **文件真实**：甲方向乙方提供的原借款协议、付款凭证、A→甲《债权转让协议》及通知凭证均为真实原件或与原件一致的复印件；
7. **主体资格**：甲方签订、履行本协议已取得必要的内部决议/授权（如公司章程或内部制度要求股东会、董事会决议的，决议文件作为附件四），签署人有权代表甲方。

## 第四条　文件交割与协助义务

1. 乙方付清转让价款（或按第二条第 3 款支付首期款）后 ＿＿ 个工作日内，甲方应向乙方移交下列文件**原件**（无法移交原件的，移交加盖甲方公章的复印件并注明"与原件一致"），双方签署《文件交割清单》：
   （1）原借款协议原件；
   （2）A 公司向丙方出借款项的银行转账凭证、收据/借据；
   （3）A 公司与甲方签订的《债权转让协议》原件；
   （4）就 A→甲转让已通知丙方的凭证（丙方签收件、快递回执、公证书等，如有）；
   （5）丙方就原借款出具的还款承诺、对账单、催收记录等全部相关文件（如有）；
   （6）甲方内部决议/授权文件。
2. **持续协助**：交割后，如乙方追偿需要，甲方应无偿配合，包括但不限于：出具情况说明、配合乙方以甲方或 A 公司名义调取银行流水、作为证人或共同诉讼参与人出庭、协助联系 A 公司补办文件。甲方怠于协助导致乙方无法主张权利的，按第八条承担违约责任。
3. **禁止行为**：本协议签订后，甲方不得再接受丙方的任何还款、不得与丙方达成和解/减免/延期、不得放弃或减损标的债权、不得干扰乙方追偿。甲方违反前述任一行为的，该等行为对乙方不发生效力，甲方应赔偿乙方因此遭受的全部损失。

## 第五条　债权不成立或无法实现时的回补（受让方核心保护）

1. 出现下列任一情形的，乙方有权**解除本协议**，甲方应在收到乙方解除通知后 ＿＿ 个工作日内**全额退还已收转让价款**，并赔偿乙方的利息损失（按同期全国银行间同业拆借中心公布的一年期贷款市场报价利率 LPR 计算，自乙方付款之日起至实际退还之日止）及乙方为追偿已支出的合理费用（律师费、诉讼费、保全费、差旅费等）：
   （1）标的债权经查证不存在、金额不实，或原借款协议被认定无效、被撤销；
   （2）甲方违反第三条任一陈述与保证；
   （3）丙方以未收到 A→甲转让通知、或对 A→甲转让提出成立抗辩且经生效法律文书支持，致使乙方不能向丙方主张权利；
   （4）标的债权在本协议签订前已被清偿、抵销或被第三方在先受让。
2. **特别约定**：丙方自身经营恶化、无力偿还（丧失偿债能力）属于乙方受让债权后自担的商业风险，不构成甲方回补事由；**但因债权本身不真实、不完整或甲方过错导致无法实现的，不在此限。**双方确认已充分理解本款区别。
3. 乙方依本条解除协议的，已从丙方处收回的款项在退还价款时相应抵扣，避免双重受偿。

## 第六条　对债务人的通知（债权对丙方生效的关键）

1. 依据《民法典》第五百四十六条，债权转让未经通知债务人的，对债务人不发生效力。双方约定：本协议签订后 ＿＿ 日内，由甲乙双方**共同**以《债权转让通知书》（附件二）通知丙方。
2. 通知方式按以下优先级执行，至少完成一种并留存证据：（1）丙方法定代表人或授权人员当面签收（在通知书回执上签字并加盖丙方公章）；（2）中国邮政 EMS 特快专递寄送至丙方注册地址及实际经营地址，内件品名注明"债权转让通知书"，保留面单与妥投记录；（3）公证送达。电子方式（微信、电子邮件）仅作辅助，不单独作为送达依据。
3. 通知送达丙方之前，丙方向甲方清偿的，甲方应按第四条第 3 款及第七条第 3 款处理；通知送达之后，丙方仍向甲方付款的，不构成对乙方的清偿。
4. **前手转让的补正**：如 A→甲的转让此前未通知丙方，本次通知中应一并载明 A→甲、甲→乙两次转让的完整链条，视同两次转让同时通知丙方；甲方保证 A 公司对此无异议，必要时甲方负责取得 A 公司的书面确认。

## 签署与风控提示（非协议正文，签前逐项核对）

1. **最要紧的一步不是签 C→D 的协议，是拿到 B 的签字。** 债权转让协议在 C 与受让方之间签字即生效，但**未通知 B，对 B 不生效**（《民法典》第 546 条）。最稳的做法是三方同场签署：C 与受让方签转让协议，B 在协议「丙方确认」处或附件三《债务确认书》上盖章。B 不肯签字的，退而求其次用 EMS 双地址寄送通知书＋保留妥投记录，或办公证送达。
2. **证据链必须闭环**：原借款协议＋A 的银行转账凭证（现金交付的必须有 B 的收据）＋A→C 转让协议＋通知凭证，四样缺一样，打官司时都会被 B 抓抗辩点。签约前先向 C 索齐原件查验，查不到原件的，按第二条第 3 款把价款拆成「首期＋B 确认后付尾款」。
3. **先查 C 的权利干不干净**：签前到「中国裁判文书网/执行信息公开网」查 C 是否涉诉、被执行、债权是否被冻结；并要求 C 出具公司内部决议（如其章程有要求），防止事后以「无权处分/程序瑕疵」扯皮。
4. **金额要三方对平**：借款本金 5 万之外有没有利息、之前还过没有，必须在协议第一条、第三条第 4 款和附件三里写成同一个数；有过部分还款不扣减、事后被 B 拿还款凭证抗辩，是这类小额债权转让最常见的翻车点。
5. **第五条回补条款的边界要理解**：它保的是「债权是假的/有瑕疵」，保不了「B 没钱还」。若皇上还想覆盖 B 的偿债风险，只能另行要求 C 提供连带保证或抵押/质押，可在第五条外另签《保证合同》——需要的话爱妃再补。
6. **个人受让的特别提示**：转让价款须从乙方个人银行账户支付并备注"债权转让款"，保留回单——这既是乙方的受让证据，也是日后税务上证明债权成本的凭证；乙方与 C 公司如存在股东、法定代表人或亲属等关联关系，务必留存定价依据与 C 公司的内部决议，防无偿/低价转让被视同利益分配或被 C 的债权人申请撤销。
7. 本协议为通用模板，已按保护受让方（个人）侧重起草；正式签署前，建议由执业律师结合原借款协议原文、利息约定与各公司章程再复核一遍，尤其是第二条价款、第七条逾期违约金标准与第十一条管辖约定。
