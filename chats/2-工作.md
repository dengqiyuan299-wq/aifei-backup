**原理一句话**：火山方舟的接口兼容 OpenAI 协议，调 DeepSeek 不用换 SDK，只要把 Base URL 换成方舟的、Key 换成方舟的、model 填方舟上的模型 ID 就行。

**控制台操作**（console.volcengine.com/ark）：
1. 注册火山引擎账号并完成实名认证，这是调用模型的前置要求。
2. 左侧「API Key 管理」→ 创建 API Key，复制保存好。
3. 拿到 model 值（二选一）：
   - 去「模型广场」找到 DeepSeek 模型点「开通服务」，之后直接用 Model ID 调用，例如 `deepseek-v4-flash-260425`、`deepseek-v4-pro-260425`；
   - 或「在线推理」→「创建推理接入点」→ 选 DeepSeek 模型，会得到一个 `ep-` 开头的接入点 ID，把它填进 model 字段。model 字段两种 ID 都认。

**代码**（Python，先 `pip install --upgrade "openai>=1.0"`）：

```python
from openai import OpenAI

client = OpenAI(
    api_key=【已脱敏】 API Key",
    base_url="https://ark.cn-beijing.volces.com/api/v3",
)

resp = client.chat.completions.create(
    model="deepseek-v4-flash-260425",  # 或 ep- 开头的接入点 ID
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

curl 版：

```bash
curl https://ark.cn-beijing.volces.com/api/v3/chat/completions \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-v4-flash-260425",
       "messages": [{"role": "user", "content": "你好"}]}'
```

**[2026-10-27 16:30]** 爱妃：皇上，这个问题分几种情况，核心看一个数：**D买这笔债权花了多少钱，和最后收回来多少钱，差多少、收回来的钱里有没有利息。** 5万本金本身不是收入，这一点先说清。

**一、企业所得税（主要风险在这里）**

- **平价受让、平价收回**：D花5万从C买入，又从B收回5万本金——本金是收回自己的债权成本，**不算收入、不缴企业所得税**。账上就是「其他应收款/债权」买入，再冲销收回，干干净净。
- **折价受让**：比如D花3万买了5万的债权，最后收回5万——多出的2万是实打实的收益，要并入应纳税所得额，**按25%缴企业所得税（约5,000元）**。小微企业有优惠税率的按优惠算。这是很多人忽略的一笔：折价的利润不是免税的。
- **收回来的钱里有利息**：B支付的利息、逾期违约金部分，对D是利息收入，**全额计入企业所得税应税收入**。协议里我之所以让B在还款时备注、把本金和利息分开写，就是为了账上能把这两部分分开。
- **收不回来**：如果B最后只还了一部分或一分不还，差额是资产损失。企业所得税前可以扣除，但必须按国家税务总局2011年第25号公告留存证据（协议链条、催收记录、法院文书或B破产/注销证明等），**不能自己做个账就核销了**，这是税务稽查的常见挑点。

**二、增值税（有两个模糊地带）**

- **收回本金**：不是销售行为，**不缴增值税，也不用给B开发票**。B那边凭转让协议＋通知书＋银行回单做还款凭证即可。
- **收利息**：利息属于「贷款服务」范畴，D如果是一般纳税人，利息收入原则上按**6%**缴增值税并应向B开票；小规模纳税人按征收率。这块各地执行口径有差异，是第一个模糊点。
- **折价收益是否缴增值税**：D若是把债权再转手卖掉赚差价，可能被认定为「金融商品转让」按差价6%缴增值税；但D是自己持有到期向B收款的，主流口径不按金融商品转让征税。这是第二个模糊点，金额大时值得先问主管税务机关。

**三、印花税（基本无风险）**

债权转让协议**不在印花税的应税凭证清单里，不用缴印花税**。企业之间的借款合同也不同于银行借款合同，同样不缴。这一项可以放心。

**四、最容易踩的实操坑（比税率本身更要命）**

1. **买债权的钱必须走对公转账、留凭证。** D付给C的转让款，就是D将来主张「5万里有5万是我的成本」的唯一证据。如果走现金或个人账户、没凭证，税务上成本认定不了，**收回的5万可能被全额当收入征税**——这是最大的一个雷。
2. **收款必须进D的对公账户**，不要进股东或法人个人卡，否则既有税务上的收入性质认定问题，又有公司财产混同的法律问题。
3. **关联公司之间要小心**：如果C、D是关联方，无偿或明显低价转让，税务机关可以按特别纳税调整规则核定；无偿受让的一方，还可能被视同接受捐赠，按债权公允价值确认收入缴税。不关联的正常交易不用担心这一条。
4. **账务科目别记错**：买入时记债权资产，收回时先冲本金、多出部分才确认收入；一进账就全记「营业外收入」的话，平价收回也会被多征税。

**小结**：平价买、平价收、全程对公、账上本息分开——基本没有税务风险；真正的税负只出现在三个地方：**折价的差价、收到的利息、以及凭证链断裂导致成本不被认定**。金额只有5万，税额本身不大，但凭证这条建议从签约付款那天就做对，后补很麻烦。

**一、为什么可以**

1. **个人的个税（主要区别）**
