**原理一句话**：火山方舟的接口兼容 OpenAI 协议，调 DeepSeek 不用换 SDK，只要把 Base URL 换成方舟的、Key 换成方舟的、model 填方舟上的模型 ID 就行。

**控制台操作**（console.volcengine.com/ark）：
1. 注册火山引擎账号并完成实名认证，这是调用模型的前置要求。
2. 左侧「API Key 管理」→ 创建 API Key，复制保存好。
3. 拿到 model 值（二选一）：
   - 去「模型广场」找到 DeepSeek 模型点「开通服务」，之后直接用 Model ID 调用，例如 `deepseek-v4-flash-260425`、`deepseek-v4-pro-260425`；
   - 或「在线推理」→「创建推理接入点」→ 选 DeepSeek 模型，会得到一个 `ep-` 开头的接入点 ID，把它填进 model 字段。model 字段两种 ID 都认。

**代码**（Python，先 `pip install --upgrade "openai>=1.0"`）：

```python
from openai import OpenAI

client = OpenAI(
    api_key=【已脱敏】 API Key",
    base_url="https://ark.cn-beijing.volces.com/api/v3",
)

resp = client.chat.completions.create(
    model="deepseek-v4-flash-260425",  # 或 ep- 开头的接入点 ID
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

curl 版：

```bash
curl https://ark.cn-beijing.volces.com/api/v3/chat/completions \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-v4-flash-260425",
       "messages": [{"role": "user", "content": "你好"}]}'
```
